===== SLIDE 4 =====
一个小程序，服务两类用户：消费者咨询 + 律师获客管理
C 端 · 消费者
「客户咨询」入口
● 7×24 小时 AI 智能法律咨询
● 覆盖劳动纠纷、婚姻家事、合同纠纷等常见问题
● 快速梳理法律风险与维权路径
● 降低法律咨询门槛，前置筛选真实需求
B 端 · 律师 / 法律从业者
「法律顾问」入口
● AI 自动分析咨询会话，生成意向客户线索
● 客户意向评级（高 / 中 / 低）与案件标签
● 诉求拆解、风险评估、跟进建议
● 提升律师获客效率，精准匹配案源
数据闭环： C 端咨询会话 → AI 结构化分析 → B 端律师线索池 → 转化为委托案件

===== SLIDE 6 =====
核心功能：C端智能咨询五步流程 + B端意向客户自动分析
C 端 · 智能咨询对话流程
1. 用户输入
文字或语音输入法律问题
→
2. 意图识别
识别案件类型与用户诉求
→
3. 知识库检索
RAG 检索相关法条与案例
→
4. 生成回答
结构化输出法律建议与依据
→
5. 风险提示
AI 仅供参考，引导线下委托
B 端 · AI 意向客户分析流程
输入
消费者完整咨询会话记录
含多轮对话上下文
用户诉求与证据描述
→
AI 结构化分析
● 案件类型标签（劳动 / 婚姻 / 合同）
● 用户诉求拆解与关键点提取
● 证据现状与风险评估
● 意向评分：高 / 中 / 低
● 跟进建议与沟通要点
→
输出
意向客户线索列表
含完整 AI 分析报告
支持按案件类型、意向等级筛选
标记跟进状态

===== SLIDE 7 =====
MoMA 平台模型调用：多模型智能路由，按场景最优匹配
DeepSeek-V3
复杂推理 · 长文本分析
● 复杂法律逻辑推理与案例分析
● 长咨询会话的上下文理解
● 法律文书初稿生成与润色
● B 端深度意向分析报告
GLM-5.2
通用对话 · 结构化输出
● C 端日常法律咨询对话
● 结构化法律建议输出
● 多轮对话上下文管理
● Function Calling 工具调度
千问-Turbo
快速响应 · 意图识别
● 用户意图快速分类识别
● 法律实体与关键词抽取
● 高频简单问题秒级响应
● 降低 API 调用成本
智能路由策略： 系统根据任务复杂度、上下文长度、响应延迟要求自动选择最优模型。简单意图识别走千问-Turbo（&lt;500ms），常规对话走 GLM-4，复杂推理与长文本分析走 DeepSeek-V3。所有模型均通过 MoMA 平台统一接入，支持 Function Calling 调度法条检索、案例匹配、风险评估等外部工具，兼顾效果、速度与成本。

===== SLIDE 10 =====
核心 Prompt 工程策略与 Function Calling 工具调用设计
Prompt 工程四大策略
① 系统角色设定
设定资深法律顾问人设，明确专业领域、回答边界与免责声明，确保输出严谨合规
② RAG 上下文动态注入
将向量库检索到的法条与案例按相关性排序后动态拼入 Prompt，引用原文标注来源条款
③ 输出格式结构化约束
强制三段式输出：法律依据 → 证据清单 → 维权路径，降低幻觉，提升用户可读性
④ 多轮记忆管理
会话摘要 + 关键事实提取，控制上下文窗口长度，超 10 轮自动压缩历史对话
Function Calling 工具调用链
工具一：法条检索
入参：案件类型 + 关键词 → 向量检索 Top-K 法条 → 返回条款原文与司法解释
触发条件：用户提问涉及具体法律问题时自动调用
▼
工具二：案例匹配
入参：案情摘要 + 争议焦点 → 检索同类裁判文书 → 返回案号、裁判要旨与判决结果
触发条件：用户询问"类似案件怎么判"时调用
▼
工具三：风险评估
入参：证据清单 + 案件事实 → 规则引擎 + LLM 联合评估 → 返回风险等级与胜诉概率区间
触发条件：用户描述完整案情后自动触发，B 端分析必调
LEGAL-AGENT · MVP v1.0 · MoMA

===== SLIDE 14 =====
商业价值：应用前景 · 客户群体 · 商业模式
应用前景
市场趋势
法律服务数字化加速，AI 法律咨询渗透率持续提升
需求痛点
C 端：咨询成本高、响应慢、信息不对称
B 端：获客成本高、线索筛选效率低
差异化优势
双角色闭环：C 端获客 + B 端转化一体化
基于 MoMA 平台多模型路由，成本可控
微信小程序生态，获客门槛低
潜在客户群体
C 端 · 大众消费者
面临劳动纠纷、婚姻家事、合同纠纷等常见法律问题的普通用户，需要低成本、即时的法律咨询
B 端 · 中小律所 / 独立律师
缺乏专业营销团队的中小律所和独立执业律师，需要高效获客和线索管理工具
B 端 · 企业法务部门
中小企业法务团队，需要 AI 辅助合同审查、合规咨询和员工法律咨询
B 端 · 法律科技平台
可通过 API 授权方式，将 AI 咨询能力嵌入现有法律科技产品
商业模式
① SaaS 订阅（律所端）
律所/律师按月或按年订阅工作台，含线索管理、AI 分析报告、客户跟进功能
② 按次咨询费（C 端增值）
基础咨询免费引流，深度法律意见书、文书生成等增值服务按次收费
③ 律师获客分成
C 端用户通过平台委托律师，按案件代理费比例收取渠道分成
④ 企业 API 授权
向企业法务和法律科技平台开放 API，按调用量或年度授权费收费
愿景：让每一个人都能获得专业、即时、可负担的法律咨询，让每一位律师都能精准匹配案源
